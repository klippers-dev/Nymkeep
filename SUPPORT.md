# Getting help

Read [INSTALLATION.md](docs/INSTALLATION.md) and
[platform status](docs/release/PLATFORM_STATUS.md). There is no public installer
yet; source archives and unsigned CI candidates are for development.

Search existing issues before using the bug or feature form. Include the app
version/commit, OS, steps and a synthetic example. Never paste original sensitive
text, private images, mappings or credentials. Security reports follow
[SECURITY.md](SECURITY.md).

Nymkeep is independently maintained by Klippers. Help and contribution review
follow maintainer availability; there is no guaranteed support SLA. General
questions can go to **contact.klippers@gmail.com**.
