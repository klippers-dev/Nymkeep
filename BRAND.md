# Nymkeep brand record

Updated: 2026-09-21.

## Selected name

**Nymkeep** (`nim-keep`) combines `nym`—a pseudonym or alias—with `keep`: real
details remain locally held. It is short, pronounceable in Indian and global
English, and broad enough for desktop, browser, Office, and document workflows.

Tagline: **Real details stay local.**

## Preliminary clearance

- Exact-name searches across the public web, software companies, GitHub, Apple
  App Store, Google Play, and indexed trademark pages returned no obvious Nymkeep
  product or company conflict on 2026-09-21.
- Official RDAP queries returned `404 Not Found` for `nymkeep.com` and
  `nymkeep.ai`, indicating no current registration at query time. Availability
  can change at any moment and must be confirmed at checkout.
- This is preliminary screening, not a legal clearance opinion. Before public
  launch, run exact and phonetic searches in target jurisdictions and relevant
  software/SaaS classes through counsel or a trademark professional, then file
  the word mark and register domains/handles together.

Rejected names included several names already used by redaction, clipboard,
privacy-vault, PII-masking, and software products. Nymkeep was selected after
exact-name and domain screening found no obvious conflict at the time checked.

## Mark system

The geometric `N` has four parts:

1. cyan source rail — useful context entering Nymkeep;
2. amber alias segment — the reversible placeholder;
3. frost return rail — the original remains under user control;
4. cyan lower return — restored context completing the path.

The gaps are intentional: live details do not travel with the shared text. The
mark avoids shields, locks, checkmarks, and other generic security symbols. The
canonical SVG is `public/nymkeep-mark.svg`; the concept presentation is
`public/nymkeep-brand-board.png`.

## Competitive position

Primary comparison: an active Mac and Chrome prompt-privacy product with local
prompt checks and placeholder restoration.

| Buying criterion                | Nymkeep today                                         | Leading prompt-privacy competitor              | Position             |
| ------------------------------- | ----------------------------------------------------- | --------------------------------------------- | -------------------- |
| Windows desktop workflow        | Native global shortcuts and selection capture         | Mac + Chrome focus                            | Nymkeep ahead        |
| Browser send interception       | Planned companion                                     | Shipping Chrome extension                     | Competitor ahead     |
| Local processing                | Protect/Restore offline                               | Local prompt checks                           | Parity               |
| Reversible aliases              | Stable, boundary-aware restore                        | Placeholder restoration advertised            | Parity               |
| No-account local use            | Yes                                                   | Sign-in and subscription required             | Nymkeep ahead        |
| Manual missed-detail correction | Temporary selection correction                        | Safer-version editing advertised              | Mixed                |
| Detection transparency          | Deterministic validators + disclosed local NER status | Implementation detail not publicly comparable | Nymkeep clearer      |
| Office workflow                 | Cross-app text workflow; Excel formatting pending     | Supported AI apps rather than Office workflow | Nymkeep opportunity  |
| Release maturity                | Pre-beta; signing and device matrix pending           | Signed/notarized shipping product             | Competitor ahead     |
| Corporate administration        | Signed policies/audit/Intune planned                  | No comparable public admin story found        | Unproven opportunity |

Nymkeep is already stronger for account-free Windows workflows and transparent
local control. It is not yet stronger as a finished commercial product: browser
interception, signing, distribution, onboarding, and production support remain
gaps. The defensible corporate advantage will come from format-preserving Office
support, Intune deployment, signed policies, encrypted local dictionaries, and
counts-only audit evidence without adding cloud scanning.
